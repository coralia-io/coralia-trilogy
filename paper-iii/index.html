Aperture: The Geometry of Coralia

Emma Cecile · 2026-01-23 · Version 1.0 · Preprint

Abstract

We classify 12-element subsets S ⊂ {0, …, 35} satisfying four structural constraints: a fixed prefix gap pattern, strictly decreasing terminal gaps, terminal gaps drawn from the Fibonacci–Lucas alphabet, and a lower bound on terminal gaps. Exhaustive enumeration shows that exactly one such subset exists, namely C = {0, 1, 2, 3, 5, 7, 9, 12, 15, 23, 30, 35}. We prove that each of the four axioms is necessary: removing any one produces multiple solutions. A uniqueness result establishes that the induced midpoint-quantization operator is uniquely determined by the gap vector up to translation. A boundary-compatibility argument explains why the prefix endpoint 15 and terminal gaps (8, 7, 5) together force the ceiling 35. Finally, we show that avoidance of large Fibonacci and Lucas values holds for C at 35 but is not derivable from the minimal axiom set over all ceilings.
